# NEXTMBS

Next.js App Router site for NEXTMBS medical billing.

## Scripts

```bash
npm run dev     # http://localhost:3000
npm run build
npm start
```

## Structure

```text
src/app/                 App Router pages and layout
src/app/services/[slug]  Static service pages
src/components/ui/       Navbar, footer, home, service templates
src/data/                Contact details and service content
public/images/           Site images and logo
```
